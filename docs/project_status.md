## 项目定位

本项目最初是 Godot UI 系列课程的背包示例。当前同时维护可运行的教学工程和可复用的 `addons/simple_inventory` 插件。课程适合按“布局 → 槽位显示 → 数据绑定 → 使用与拖拽意图 → 装备界面 → 插件接入”逐步讲解。

核心规则与界面分开：背包/装备组件维护状态，UI显示结果并向宿主发出操作意图。宿主负责治疗、角色属性、任务与游戏存档；插件负责物品容器、装备槽和版本化背包快照。

课程可归入 Godot 基础教程的 UI 实战专题，上游插件仓库继续独立维护。教学阶段应固定工程提交，避免读者按旧教程操作开发分支。旧课程中的接口需对照迁移说明逐课核验，当前尚未完成逐课修订。
